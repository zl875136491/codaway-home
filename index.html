How it works

三端协同，一条加密链路

Pocket 在手机发指令，Pipe 零知识中继，Worker 在桌面执行——无需暴露公网端口。

01 · Pocket

iOS 原生控制台

会话编排、终端流、Git 巡检与 Live Activity，把桌面 Agent 握在手里。

02 · Pipe

零知识密文中继

CPS-v1 密文帧路由。中继不解密、不落盘明文，只做盲转发。

03 · Worker

桌面常驻守护

Mac / Linux 反向连接，开机自启。零入网端口，亚毫秒级唤醒。
