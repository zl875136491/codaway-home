Roadmap

版本特性与发展路线

Pocket · Worker · Pipe 三端协同演进，持续拓展移动端自主编程边界。

Pocket (iOS) v0.3.0
  • 前台任务进度卡片与状态监控（灵动岛规划中）
  • 原生双向低延迟 PTY 终端流与 ANSI 渲染
  • 工作区 Git 状态与横屏代码差异比对
  • Codex / Claude Code / OpenCode / DeepSeek 指令面板
  • Face ID / Touch ID 与 Keychain 凭据守护
Worker (Mac/Linux) v0.2.0
  • 零对外开放端口的后台守护（Launchd / Systemd）
  • 跨平台伪终端会话驱动与 SIGINT 优雅中断
  • 多工作区并发索引与智能代码摘要
  • Apple Silicon 签名自愈与无缝二进制替换
  • 二维码与限时安全配对短码分发
Pipe (Relay) v0.3.0
  • 高性能 Go WebSocket 密文帧路由（零明文盲转）
  • 企业级 SMTP 邮箱激活与 6 位验证码分发
  • 源 IP 与目标邮箱滑动窗口双重限流
  • 会话状态、公钥指纹与审计日志持久化
  • 离线消息缓冲与断网自动重发
Milestones

产品演进阶段

从点对点安全管道，迈向多工作站集群与多 Agent 协同治理。

Phase 1 · 端到端加密与中继网络 已完成

制定 CPS-v1 密文规范，实现 Curve25519 协商与 ChaCha20-Poly1305 密文流中继，完成首代 Pocket 与 Worker 连通。

Phase 2 · Pocket 原生体验与多驱动协同 进行中

前台进度感知、横屏 Git 比对与指令快捷板已实现；后台推送、灵动岛及完整驱动验收仍在推进。

Phase 3 · 多节点 Mesh 与 Web 控制台 进行中

交付产品主页与注册中枢，支持多工作站集群管理、企业 SMTP 动态验证码及快速分发通道。

Phase 4 · 多 Agent 自治编排与协同治理 规划中

支持多 Agent 跨工作区协同，引入审批流断点、自动化测试拦截与代码审查评分。

Phase 5 · 移动语音交互与端侧推理 规划中

集成低延迟语音双工流，探索 Apple Silicon 本地小型辅助模型，实现离线意图识别与快捷转写。
